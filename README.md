# Python Module 03: Data Structures & CLI Interactions

Welcome to **Python Module 03** of the 42 Tokyo Python curriculum. This module covers advanced data structures in Python, command-line arguments processing, and data transformations.

## 🎯 Objectives

- Parse and process command-line arguments using `sys.argv`.
- Work effectively with Python built-in data structures: lists, tuples, sets, and dictionaries.
- Utilize dictionary mappings, coordinate systems, and hash lookups.
- Implement filtering, mapping, and aggregating operations on data streams.
- Transform and reshape complex nested data structures.
